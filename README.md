# GHASHASH STORE BOT

بوت ديسكورد لمتجر المنتجات، يعرض المنتجات في شبكة Embeds فاخرة مع نظام تذاكر شراء.

---

## ⚙️ قبل التشغيل (مرة واحدة فقط)

1. ثبّت Node.js 20+ (تم تثبيته على هذا الجهاز).
2. افتح المجلد في الطرفية وشغّل:
   ```
   npm install
   ```
   (لتثبيت المكتبات — تم تنفيذها بالفعل)

---

## 🚀 التشغيل

- اضغط **start.bat** مرتين OR شغّل:
  ```
   npm start
   ```
- ستظهر رسالة "✔ البوت يعمل الآن باسم: ..."

> **هام:** البوت يعمل ما دامت هذه النافذة مفتوحة. إذا أغلقتها أو فصلت جهازك، يتوقف البوت.
> لتشغيل دائم 24/7 رفّع الكود على استضافة (مثل Render / Heroku / VPS) أو جهاز دائم التشغيل.

---

## 📌 أوامر البوت (Slash Commands)

| الأمر | الوظيفة |
|-------|---------|
| `/createstore` | يعرض زر **Create Store** لإضافة المنتجات يدويًا من الديسكورد (Admin) |
| `/ads` | ينشر إعلانًا لكل منتج (تصميم فاخر) في نفس القناة (Admin) |
| `/products` | يعرض كل المنتجات (شبكة المتجر) |
| `/setup role:@رتبة الدعم` | يحدد رتبة الدعم الفني التي تُمنشن في التذاكر (Admin) |
| `/ping` | تجربة أن البوت يعمل |

---

## 🛒 طريقة الاستخدام

### إضافة منتج (Create Store)
1. اضغط `/createstore`
2. اضغط زر **Create Store**
3. اكتب: اسم المنتج، السعر، رابط الصورة، الوصف
4. تنشر بطاقة المنتج فورًا مع زر **Buy**

### شراء منتج (Buy)
1. العميل يضغط زر **Buy** تحت أي منتج
2. تُفتح **تذكرة** في نفس القناة باسم حساب العميل
3. يُمنشن رتبة الدعم الفني (التي حددتها بـ `/setup`)
4. داخل التذكرة أزرار:
   - ✅ **تسليم / استلام** — تأكيد تسليم المنتج
   - 🔒 **قفل** — منع الكتابة في التذكرة
   - 🔐 **إغلاق** — أرشفة التذكرة
   - 🗑️ **حذف** — حذف التذكرة نهائيًا

## 🔧 الإعدادات (config.json)

| الحقل | المعنى |
|-------|--------|
| `token` | توكن البوت (سري، لا تشاركه) |
| `botName` | اسم البوت المعروض |
| `currency` | رمز العملة |
| `supportRoleId` | ID رتبة الدعم (أو ثبّته بأمر `/setup`) |
| `color` / `accentColor` | ألوان البطاقات |

## 📁 الملفات

- `config.json` — الإعدادات
- `data/store.json` — المنتجات المحفوظة

## ⚠️ أمان

- **لا تشارك التوكن** مع أي أحد أبدًا.
- إذا تسُرّب التوكن، أبطله فورًا من Developer Portal وأعد إنشاء جديد.
- عالج مدفوعاتك (PayPal / فيزا) خارج البوت بحيث تتواصل مع المشتري في التذكرة وتؤكد الاستلام.

---

## ❓ إضافة البوت للسيرفر / توكن جديد

1. ادخل على https://discord.com/developers/applications
2. أنشئ تطبيق → تبويب **Bot** → **Reset Token** لنسخ توكن جديد
3. من تبويب **OAuth2 → URL Generator**: فعّل `bot` + `applications.commands` والصلاحيات، افتح الرابط وأضف البوت لسيرفرك
4. حدّث `token` في config.json ثم شغّل
